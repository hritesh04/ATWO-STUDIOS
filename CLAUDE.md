# CLAUDE.md - Project Instructions

## Before Writing Any Code
- Always read `plan.md` first to understand the full optimization and design plan
- Always check `status.md` to know which phase of development we are currently in
- Only work on tasks within the current active phase unless explicitly told otherwise

## Project Overview
- Next.js 16 + React 19 website for ATWO Studios
- Tailwind CSS 4 for styling
- Motion library for animations
- Lenis for smooth scrolling

## Key Commands
- `npm run dev` — start dev server
- `npm run build` — production build (use to verify optimizations)
